# Brand Assets

Authoritative brand assets for the DClaw Marketing product UI.

**DClaw and DKube are separate product brands** under One Convergence, sharing the same visual system (palette, typography, motion, component vocabulary) but with **distinct logos**. The DKube lockups are bundled for parent-brand attribution / co-marketing only; the product itself uses the DClaw mark.

The DClaw marks below are **placeholder**, generated as simple geometric SVGs using brand tokens. Replace with the final designed mark when ready.

## Rules

- **Aspect ratio is locked.** Always scale uniformly. Never stretch, squash, distort.
- **Use the supplied SVG.** Don't redraw, recolor, or re-letter the wordmark.
- **Clear space:** keep a margin equal to the height of the cube's top face on all sides.
- **Minimum size:** 24px tall for the icon, 96px wide for the wordmark.
- **On photography:** use `dkube-logo-white.svg` over a dark scrim (≥50% black at logo position). Never place purple wordmark on busy or low-contrast photo.
