# Brand Assets

Authoritative brand assets for the DClaw Marketing product UI. Sourced from `/design/dkube-design-system/project/assets/` (the Claude Design ingest).

## Layout

| Path | Use |
|---|---|
| `logos/dkube-logo-purple.svg` | Primary wordmark — light surfaces |
| `logos/dkube-logo-white.svg` | Reverse wordmark — dark surfaces, photo scrims |
| `logos/dkube-tm-logo-purple.svg` | Wordmark with trademark glyphs (footer attribution) |
| `logos/dkube-icon-purple.svg` | App icon — light surfaces (also serves as favicon) |
| `logos/dkube-icon-white.svg` | App icon — dark surfaces |
| `logos/dkube-icon-logo-purple.avif` | Raster fallback for low-resolution surfaces |
| `icons/icon-magic.svg`, `icon-scalable.svg`, `icon-trust.svg` | Three-pillar feature icons |
| `icons/arrow-icon.svg`, `arrow-top-right.png`, `round-arrow-right.svg` | CTA arrows |
| `icons/si-linkedin.svg`, `si-twitter.svg`, `si-insta.svg` | Social icons |
| `icons/menu-icon.svg` | Mobile menu glyph |
| `customer-logos/` | Partner / customer logos (Cisco, VMware) — rendered desaturated in the trust strip |
| `imagery/img-*` | Brand-supplied photography — industry verticals + product context |

## Rules

- **Aspect ratio is locked.** Always scale uniformly. Never stretch, squash, distort.
- **Use the supplied SVG.** Don't redraw, recolor, or re-letter the wordmark.
- **Clear space:** keep a margin equal to the height of the cube's top face on all sides.
- **Minimum size:** 24px tall for the icon, 96px wide for the wordmark.
- **On photography:** use `dkube-logo-white.svg` over a dark scrim (≥50% black at logo position). Never place purple wordmark on busy or low-contrast photo.
