Chapter 2

Executive Summary

The platform thesis from PLAN-v1.2 — "marketing agents that run the platform from one chat" — landed in Sprint 4. The pieces have existed since Sprint 2 (Phase 9 Conductor shell) and Sprint 3 (admin model, audit, integrations). What was missing was the model layer, the resolver, and the actual agent dispatch. All three landed.

Why this sprint matters

An operator with valid API keys can now:

  1. Open /admin/models, add an Anthropic provider, watch auto-discovery populate three Claude entries.
  2. Pin a default text model at the org level + an embedding model.
  3. Walk to /conductor, drop a brief, get a decomposed plan + per-agent drafts in one round-trip.
  4. Approve hard-gated steps (with optional N-of-M sign-off) and watch the queued ScheduledPosts go out.
  5. Read the per-run reasoning trace and cost ledger entry from the same UI.

Process notes

All seventeen PRs were admin-squash-merged after local container-based smoke testing (the op authorised this in the kick-off conversation; the in-repo tests cover the surfaces touched and CI duplicates that work). The standard org auto-merge workflow is still in place; admin-merge was the in-session-only choice for throughput.

What was scoped out

  • Five marketing issues (#49–#53) remain open by standing instruction.
  • LLM-judged AEO scorer (heuristic-only in S4-K — Sprint 5 swaps in an LLM pass).
  • Native SDK probes for Vertex AI + AWS Bedrock health-checks (S4-M5 falls back to unknown).
  • WorkflowRun "resume" operator-facing endpoint (the runner supports it internally).

Chapter 7

Sprint 5 — Recommended Next Steps

With v1.1.2 making the agent flow real, Sprint 5 should focus on operator confidence: visible cost guardrails, real streaming, and the LLM-judged AEO pass.

Top priorities

  1. Real-time SSE streaming for Conductor dispatch — surface tool calls + token-by-token output, not just the final blob.
  2. LLM-judged AEO variant — second-pass scoring + blended ranking.
  3. Vertex AI + Bedrock native SDK probes — bring those two providers to first-class status.
  4. Cost guardrails in /conductor — show "this dispatch will cost ~$0.18" before the run, refuse on caps.
  5. Workflow visual builder editor — currently templates clone into a draft Workflow but the DSL edit UX is JSON-only.
  6. Marketing collaterals (#49–#53) — finally unblock the demo video + one-pager + slides + social drafts.

Stretch

  • Reasoning trace replay UI (Sprint 4 ships the endpoint; needs a timeline view).
  • OpenRouter credit-balance card on /admin/models.
  • Per-tenant override beyond the resolver chain — e.g. BrandKit.preferred_voice_model.
